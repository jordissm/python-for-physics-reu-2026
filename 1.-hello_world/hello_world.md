# Hello World

## Your First Test Script

After setup, try making a small Python file:

1. In VS Code, create a file named `hello.py`.
2. Add this code:

   ```python
   print("Hello, physics Python!")
   ```

3. Save the file.
4. Run it from the terminal:

   ```bash
   python hello.py
   ```

On macOS, Linux, or Windows with WSL, if `python hello.py` does not work, try:

```bash
python3 hello.py
```
